## What the available tests establish

- The [CI run at the audited main revision](https://github.com/manideepreddyyanala4-svg/LLM-RAG/actions/runs/43042149127) and the [release PR CI run](https://github.com/manideepreddyyanala4-svg/LLM-RAG/actions/runs/42996397719) both succeeded. Its smoke log reports **84 tests run, 8 skipped, 76 passed** after synthetic demo generation and a hash-checked UCI download. The [test file](https://github.com/manideepreddyyanala4-svg/LLM-RAG/blob/3e919f9b740e3c5516c40a77072c42c59e22e70c/test_evidenceops.py#L38) explains the eight skips: the uncommitted original starter dataset is absent. The CI run also passed a separate [PostgreSQL/pgvector smoke job](https://github.com/manideepreddyyanala4-svg/LLM-RAG/actions/runs/43042149127/job/130596480760) using synthetic records. The archived 75 passed and 9 skipped result reflects one additional skip when the UCI files were absent. The older 73 passed and 8 skipped result still lacks its original run log. CI uses mocks for AI behavior; it does not run Ollama inference.
- The UCI test counts raw rows and labels separately from the application summary: **1,941 records**, seven mutually exclusive fault labels, and category counts **158, 190, 391, 72, 55, 402, 673** in source order ([test_evidenceops.py:88](https://github.com/manideepreddyyanala4-svg/LLM-RAG/blob/3e919f9b740e3c5516c40a77072c42c59e22e70c/test_evidenceops.py#L88)). These are proportions among fault records, not a production rejection rate.
- The [README model results](https://github.com/manideepreddyyanala4-svg/LLM-RAG/blob/3e919f9b740e3c5516c40a77072c42c59e22e70c/README.md#L193) and [release PR narrative](https://github.com/manideepreddyyanala4-svg/LLM-RAG/pull/1) report small regression, held-out, injection and steel case runs. The [grader](https://github.com/manideepreddyyanala4-svg/LLM-RAG/blob/3e919f9b740e3c5516c40a77072c42c59e22e70c/evaluation.py#L368) uses status and phrase checks. Raw ai_evaluation.json is ignored by Git and was unavailable in this audit, so exact model outcomes, latency and repeatability remain reported results, not independently reproduced findings. No human-reviewed accuracy benchmark is present.

## Questions to defend in an interview

1. Why are synthetic Line B and UCI evidence kept separate? What denominator is absent from the UCI data?
2. How are old or deleted document versions excluded, and when is a chunk re-embedded?
3. How do BM25, cosine ranking and reciprocal rank fusion differ here? Why do their scores not prove method superiority?
4. What do the exact-quote and model-support checks each catch, and what false claims can still pass?
5. Which agent decisions are enforced in Python? What prevents the MCP process from approving a ticket?
6. What do the three tokens protect, and why are they insufficient for a multi-user network service?
7. What did the 84-test CI run actually execute, what was skipped, and which tests mock Ollama?
8. How are the real-model cases graded, and why are their reported counts not a benchmark or an accuracy percentage?
9. Which design, debugging and validation steps did you personally perform, and where did AI assistance contribute?
